# cgpa_calculator
A simple CGPA Calculator built in Python that helps students calculate their CGPA based on subject grades and credits.
1. Title

CGPA Calculator

A Simple Academic Performance Calculation System
Developed by: Maheshwari
Department: BE Electrical and Electronics Engineering (EEE)
2. Project Overview

The CGPA Calculator is a software application designed to calculate a student's Cumulative Grade Point Average (CGPA) accurately and efficiently. It helps students track their academic performance across multiple semesters and understand their overall progress.

3. Objective
Calculate CGPA quickly and accurately.
Reduce manual calculation errors.
Provide a user-friendly interface.
Help students monitor academic performance.
Generate academic reports for future reference.
4. Problem Statement

Manual CGPA calculation:

Is time-consuming.
Can lead to calculation errors.
Requires knowledge of grading formulas.
Makes semester-wise tracking difficult.

The CGPA Calculator automates the entire process.

5. Project Description

The system accepts:

Subject names
Credits
Grade points

The calculator:

Computes Semester GPA (SGPA)
Calculates overall CGPA
Displays results instantly
Generates PDF reports (optional feature)
6. Technologies Used
Programming Language: Python
GUI: Tkinter
PDF Generation: ReportLab
Version Control: GitHub
7. System Workflow
Enter subject details.
Enter credits and grades.
Convert grades into grade points.
Calculate SGPA.
Calculate CGPA.
Display results.
Generate report if required.
8. Features
Easy-to-use interface

9. Rules for Using the Calculator
Enter valid credits for each subject.

Ensure all fields are filled before calculation.
